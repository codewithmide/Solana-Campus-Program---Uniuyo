# Contributing

## Ways to help

- Fix a confusing explanation or broken link.
- Share a tested alternative solution.
- Add a small exercise with a result other students can check.
- Improve instructions for different laptops and operating systems.

## Proposing a curriculum change

Open an issue to describe what you want to improve, or propose a change. For a new challenge, include:

1. objectives and prerequisites;
2. an estimated duration;
3. acceptance criteria;
4. hints that do not reveal the full answer;
5. a reference solution or helpful hints;
6. safety notes where signing, tokens, or authority are involved.

Do not include wallet secrets, generated keypair files, private RPC URLs, or real student personal data.
