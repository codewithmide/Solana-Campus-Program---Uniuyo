# Curriculum

If you know basic JavaScript or TypeScript, Git, and your terminal, you are ready to begin. You will pick up Rust and Solana concepts as you go.

## How to use each week

1. Read the objectives and complete prerequisites.
2. Attempt the core task before reading `SOLUTION.md`.
3. Save evidence: test output, explorer link, screenshot, or demo URL.
4. Commit a short note explaining what you learned or where you got stuck.
5. Try applying the idea to your own project.

Solutions are reference approaches, not answer keys. Equivalent implementations that satisfy the acceptance criteria are encouraged.

## Track structure

| Phase | Weeks | Focus |
| --- | --- | --- |
| Foundations | 0–2 | Safety, account model, RPC, transactions and confirmation |
| Application layer | 3–4 | Tokens, wallet UI, Rust fundamentals |
| Programs | 5–6 | Anchor, state, PDAs, constraints, errors and testing |
| Shipping | 7–8 | Full-stack integration, security review, demos and continuation |

You can follow the weekly exercises in order or revisit one when your project needs it. Bring questions and work in progress to campus sessions.
