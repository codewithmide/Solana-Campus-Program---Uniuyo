# Week 8 — Reference solution

There is no single code answer. A complete submission contains:

- reproducible repository and passing test evidence;
- devnet links and an honest architecture description;
- a live demo plus fallback recording;
- specific limitations and security assumptions;
- peer feedback and the team's response;
- four small, owned continuation milestones.

A narrow, reliable flow makes a stronger demo than a long list of unfinished features. Use the feedback you receive to decide what to build next.
