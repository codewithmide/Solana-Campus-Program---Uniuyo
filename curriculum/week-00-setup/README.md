# Week 0 — Setup, clusters and wallet safety

**Time:** 60–90 minutes  
**Outcome:** a verified development environment and first devnet explorer link.

## Resources

- [Solana Quick Start](https://solana.com/docs/intro/quick-start) — create a practice wallet, use devnet, and get test SOL in the browser.
- [Solana Developer Bootcamp 2026 (video)](https://www.youtube.com/watch?v=2pcm7ICRJKU) — an optional overview you can revisit as you progress.

## Core task

Create `preflight.md` in your learning repository containing:

1. operating system and pinned tool versions;
2. your **public** devnet address;
3. an explorer link showing the address on devnet;
4. three wallet safety rules in your own words.

Never include a seed phrase, private key, keypair file contents, or RPC URL.

## Acceptance criteria

- Commands run without installation errors.
- Explorer is explicitly set to devnet.
- The address has devnet SOL.
- No secret material is committed.

## Stretch

Write a check that prints tool versions and fails clearly when a prerequisite is missing.

## Project move

Create the team repository, issue labels, a one-sentence user problem, and a `SECURITY.md`.
