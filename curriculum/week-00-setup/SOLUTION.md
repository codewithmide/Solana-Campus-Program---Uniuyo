# Week 0 — Reference solution

A completed exercise includes version output, a public devnet address, and a devnet explorer URL. Use the tool versions recommended for your cohort.

Minimum safety rules:

- A public address can be shared; a seed phrase or private key cannot.
- Verify the cluster, destination, assets, and requested authority before signing.
- Use disposable devnet credentials for learning and exclude keypair files with `.gitignore`.

Before sharing your repository, check that you have not committed a seed phrase, private key, or keypair file. If you exposed a real secret, treat it as compromised and rotate it; deleting the latest line is not enough because Git retains history.
